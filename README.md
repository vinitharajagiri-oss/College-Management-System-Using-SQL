# College-Management-System-Using-SQL
This project is a College Database Management System developed using MySQL to efficiently manage and analyze student, course, and enrollment information.
# Project Overview: College Management System Using SQL

## 1. Project Title
**College Management System Using SQL**

## 2. Project Overview
The College Management System is a database project developed using SQL to store, manage, and retrieve student information efficiently. It maintains student details, course information, and enrollment records using three tables: `students`, `courses`, and `enrollments`.

The project demonstrates essential SQL concepts, including data definition, data manipulation, filtering, aggregate functions, joins, views, indexes, and transactions.

## 3. Project Objectives
- Store and manage student details.
- Maintain course information and enrollment records.
- Retrieve information from multiple tables using joins.
- Analyze student marks using aggregate functions.
- Create views to simplify frequently used queries.
- Improve data retrieval using indexes.
- Maintain data consistency using transactions.

## 4. Tools and Technologies
- **Database:** MySQL 
- **Language:** SQL
- **Tables:** Students, Courses, Enrollments

## 5. Database Tables
- **Students:** Stores student ID, name, age, department, and marks.
- **Courses:** Stores course ID, course name, and associated student ID.
- **Enrollments:** Stores enrollment ID, student ID, course ID, and enrollment date.

## 6. SQL Concepts Applied
- CREATE, ALTER, INSERT, UPDATE, and DELETE
- SELECT, WHERE, ORDER BY, and DISTINCT
- Aggregate functions: COUNT, SUM, AVG, MIN, and MAX
- Operators: ARITHMETIC, COMPARISION, LOGICAL and FILTER
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN, RIGHT JOIN, CROSS JOIN and FULL OUTER JOIN alternatives where supported
- Multiple joins
- Views and indexes
- Transactions using COMMIT, ROLLBACK, and SAVEPOINT
- Constraints such as PRIMARY KEY, FOREIGN KEY, CHECK, NOTNULL and UNIQUE KEY

## 7. Expected Outcomes
The project demonstrates how relational databases organize student information, connect related records, retrieve useful information, and support basic student performance analysis.

## 8. Conclusion
This project provides practical experience in SQL database management and helps build a foundation for more advanced database applications and data analysis projects.
